# Bolt Merchant Onboarding Automation

## Project Context
This project automates the merchant onboarding process for Bolt payment platform with visual workflow documentation in Figma.

## Goals
- Automate merchant application and approval process
- Create visual workflow documentation in Figma
- Reduce manual onboarding time by 70%
- Integrate with Bolt merchant API
- Automate document collection and verification

## Technology Stack
- **Figma MCP**: Visual workflow design and documentation
- **n8n**: Workflow automation platform
- **Bolt API**: Merchant platform integration
- **Claude Code**: AI-assisted development with GSD system
